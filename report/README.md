# 设计报告与验证证据索引

## 作品与实现

作品使用 AX7021 V3.0（Zynq-7020，xc7z020clg484-2）和 AN5642 双目 OV5640。两路 DVP 接收和独立 VDMA 将 1280×720 RGB888 帧写入 DDR；PS 合成并排预览、准备推理输入、处理两路人脸候选并估算距离；PL 上 TinyFace INT8 HLS 核承担卷积计算，AXI4-Stream 叠加器绘制最多 3 个绿框与 PEOPLE x.xM 标签，最终经 HDMI OUT 输出。模块和数据流见 ../docs/stereo_architecture.md 与 Vivado Block Design。

## 大模型协作与修正记录摘要

以下是工程过程的主题摘要，并非逐字聊天记录；原始提示词与完整回复如赛事要求，应另行导出并审阅后提交。

1. 人脸框漂移、误检与闪烁：依据现场观察，排查摄像头写帧与 PS 读帧不同步，以及灰度预处理与训练不一致的问题；修改帧边界选择和预处理后再实板检查。
2. 第二镜头扩展：先验证第二路单独显示，再加入两路接收、独立缓存和并排预览；每一步保留前一可运行版本。
3. 双目标定：采集棋盘格图像对，拒绝任一镜头角点不完整的样本，随后生成板端参数，并区分 source=stereo 与单目回退。
4. 证据边界：时序和资源取自 Vivado 报告；双目 RMS 取自离线标定；整机帧率与绝对测距误差尚需按已知距离和计时方法实测，不能由 HLS 估算推断。

Windows 2023.1 工具链、硬件接线、HLS→Vivado→Vitis 构建、JTAG 下载及串口预期输出见根目录 ../README.md；棋盘格重标定步骤见 ../stereo/README.md。与赛事推荐版本不同，选用 2023.1 是因为工程和 AX7021/AN5642 配套材料已在该版本完成联调；迁移到新版本时必须重新生成 IP、综合实现并再次上板验证。
